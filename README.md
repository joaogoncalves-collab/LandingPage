# Portfólio de João Vitor Gonçalves

Site estático em HTML, CSS e JavaScript. Os arquivos da raiz são publicados pelo GitHub Pages com origem na branch `main`, pasta `/ (root)`. O arquivo `.nojekyll` mantém a publicação direta dos arquivos.

O mapa apresenta projetos da planilha de origem marcados como `Operation`, agrupados por parceiro para leitura. A galeria de BI e o case da Central Digital SDU usam capturas locais em `assets/`.

Os SVGs dos logos têm suas páginas de origem listadas em `assets/logos/README.md`.
